# Users Fetch App

A small JavaScript app that fetches users from an API and displays them as cards.

## Features
- Fetches data with async/await and fetch
- Checks response.ok to catch server errors (like 404)
- try/catch error handling with a friendly message
- Refresh button that appears only when loading fails
- Styled with CSS (flexbox cards)

## Tech
HTML, CSS, JavaScript (Fetch API)
